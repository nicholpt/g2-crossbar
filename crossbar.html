Set up Crossbar

    
Crossbar talks to a small bridge running on your Mac. The full guide is in the repo: docs/SETUP.md.

    
1 · On your Mac

    
    
      
  1. Install tmux and Node 20+ (Homebrew).
    2. 
      
  2. Clone the repo and run bin/setup to use it anywhere over Tailscale (install Tailscale on the Mac and this phone, same account), or bin/setup --home to use it only on your home Wi-Fi.
    3. 
      
  3. It prints this Mac's address (and, for home, a pairing code).
    4. 
    

    
2 · Connect

    
Enter the address it printed: my-mac.tailnet.ts.net or its Tailscale IP 100.x.y.z, or my-mac.local for home Wi-Fi. Port 8787 is assumed.

    

      

    

    

    

      
3 · Top-line feed

      
Headlines that scroll after the clock on the glasses. Any RSS or Atom feed, one URL per line. Leave it empty to turn the feed off.
